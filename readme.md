# Neovim config 2025

## Controls

### Folds
* zc → Close fold
* zo → Open fold
* za → Toggle fold
* zM → Close all folds
* zR → Open all folds

### File exploring
<leader>o → nvim-tree
<leader>ff → file explorer
<leader>fb → file buffers
<leader>fg → file grep

### Colourschemes
<leader>cs → view/select a colourscheme from the list
